# Sample Open-Source Homebrew Games

This directory contains legal, open-source Game Boy homebrew games for testing and playing on the emulator.

## Included Games

### 1. 2048 Game Boy (`2048.gb`)
- **Developer**: Sanqui
- **Source Code**: [https://github.com/Sanqui/2048-gb](https://github.com/Sanqui/2048-gb)
- **License**: Zlib License (Permissive Open Source)
- **Controls**:
  - D-Pad (Up, Down, Left, Right): Slide tiles
  - Start (Enter): Restart game

## How to Play
```bash
cargo run --release -- examples/2048.gb
```
